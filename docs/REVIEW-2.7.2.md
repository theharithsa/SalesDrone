The main Tasks screen previously requested recipient-only work, while lead pages already exposed shared work. It now opts into GET tasks view=accessible. Sparse empty pages retain an opaque continuation; there is no count of hidden work. AES-GCM encrypted continuation tokens reuse the server cursor secret; private scan dates/IDs are not readable. Tokens bind view, effective scope, member/version and filters. Shared mutations reuse the lead-editor PATCH with expectedVersion and stable UUID identity; owner-only retitle/delete/cancel paths keep their existing policy. Delivery recipients are unchanged.
