BUILD WITH YOUR WORKSPACE

Every operation. One API portal.

Browse read, create, update and delete operations, request schemas, scopes and errors. Try it out sends real requests to your workspace. Use a test enquiry for write examples.

  1. Generate a Personal Access Token in Settings → Developer settings. Start with read-only scopes.
  2. Open Authorize and enter the raw token under personalAccessToken. The portal adds Bearer. No App Check header is needed for this credential.
  3. Choose an operation and read its required scope. Google-only operations instead require a Google Firebase ID token and App Check attestation; authorize one identity method at a time.

Authorization stays in this tab’s memory and clears on page exit. This page loads Swagger locally, has no analytics or session replay, and sends requests only to this origin. Individual lead removal means archiving. The separate Google/Admin-only lead-data reset permanently clears the pipeline; timeline corrections preserve history.
